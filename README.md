# 2026 하반기 한빛생명 GA 해외여행 프로모션 (데모)

기존 `2026promotion.mice.link` 행사 사이트의 구조(로그인 → 업적 확인 → 여행 신청 → 예약 조회)를
그대로 가져오되, **가상의 회사·회원 데이터**로 새로 설계한 로컬 테스트용 행사 홈페이지입니다.

> 등장하는 회사명, 회원 정보, 여행 상품, 예약 내역은 모두 테스트용 가상 데이터입니다.
> 실제 하나투어 / 미래에셋생명과는 무관합니다.

| 항목 | 값 |
|---|---|
| 주최 (가상) | **한빛생명** (HANBIT LIFE) |
| 주관·운영 (가상) | **비스타투어** (VISTA TOUR) |
| 행사명 | 2026년 하반기 한빛생명 GA 해외여행 프로모션 |
| 신청 접수 | 2026-09-07 14:00 ~ 2026-09-18 17:00 |
| 업적 산정 기준일 | 2026-08-31 |
| 여행지 | 6개 (다낭·호이안 / 나트랑 / 오사카·교토 / 싱가포르 / 스위스 알프스 / 이탈리아 남부) |
| 회원 | 20명 (구글 시트 → CSV) |

---

## 1. 실행

의존성 설치가 필요 없습니다. Node 18 이상이면 바로 실행됩니다.

```bash
cd Hanatour
node server.js          # 기본 포트 4000
node server.js 4173     # 포트 지정
npm start               # = node server.js
npm run dev             # 파일 변경 시 자동 재시작 (node --watch)
```

브라우저에서 `http://localhost:4000` 접속.

## 2. 테스트 계정

아이디는 **구성원코드 8자리**, 비밀번호는 **생년월일 6자리(YYMMDD)** 입니다.
로그인 화면에 데모 계정 버튼이 있어 클릭하면 자동 입력됩니다.

| 구성원코드 | 비밀번호 | 이름 | 등급 | 사용 가능 잔액 |
|---|---|---|---|---|
| `guest` | `guest` | 김서연 (첫 번째 회원) | PLATINUM | 2,450,000원 |
| 20250111 | 840128 | 신재원 | DIAMOND | 2,210,000원 |
| 20250104 | 870604 | 최민서 | DIAMOND | 2,140,000원 |
| 20250115 | 970314 | 서지안 | BRONZE | 480,000원 (대부분 여행지 신청 불가) |

잔액이 적은 계정으로 로그인하면 **업적 부족** 상태(흑백 처리 + 신청 차단)를 확인할 수 있습니다.

## 3. 디자인 전환 — 키보드 / 마우스

5개 테마 × 라이트/다크 × 레이아웃 밀도 × 모션 조합을 즉시 전환합니다.
선택한 조합은 `localStorage`에 저장되어 페이지를 이동해도 유지됩니다.

**마우스**
- 우측 하단 팔레트 버튼 클릭 → 설정 패널
- 팔레트 버튼 **위에서 휠 스크롤** → 테마 순환

**키보드**

| 키 | 동작 |
|---|---|
| `1` ~ `5` | 테마 직접 선택 |
| `[` `]` 또는 `T` | 이전 / 다음 테마 |
| `D` | 라이트 ↔ 다크 |
| `C` | 기본 ↔ 컴팩트 밀도 |
| `M` | 애니메이션 켬 / 끔 |
| `P` | 디자인 패널 열기 / 닫기 |
| `?` | 단축키 도움말 |
| `Esc` | 패널 · 도움말 닫기 |

**URL 로도 강제할 수 있습니다** (스크린샷·공유용)

```
http://localhost:4000/achievement?theme=swiss&mode=light&density=compact
```

2. 시트를 "링크가 있는 모든 사용자 - 뷰어"로 공유한 뒤

필수 컬럼: `구성원코드, 성명, 생년월일, 합산업적, 지급금액, 사용금액, 잔여금액, 달성등급`

## 6. 업적금액 규칙 (원본 사이트와 동일하게 구현)

- 사용 가능 잔액 = `잔여금액` − 진행 중(CONFIRMED) 예약의 사용 업적 합계
- 본인 1인분 금액이 잔액을 넘으면 **신청 불가** (업적금액 + 현금 혼합 결제 금지)
- 동반자 추가로 총액이 잔액을 넘으면 초과분은 **현금 결제 예정**으로 표시
- 예약을 취소하면 사용 업적이 즉시 복원됨
- `여행 취소(현금 환급)` 상품을 선택하면 잔액 전액을 현금 환급 신청으로 접수

## 7. 구조

```
server.js              무의존성 HTTP 서버 (라우팅 · 세션 · 정적 파일 · 폼 파싱)
src/store.js           데이터 계층 (CSV 파서 · 예약 CRUD · 업적 계산)
src/html.js            레이아웃 셸 · 헤더 · 푸터 · 상품 카드
src/pages.js           페이지 렌더러 11종
public/css/base.css    디자인 시스템 (토큰 · 프리미티브 · 컴포넌트)
public/css/themes.css  테마 5종 스킨 + 전환 UI
public/js/theme.js     디자인 전환 시스템 (키보드 · 마우스 · localStorage)
public/js/app.js       공통 인터랙션 (모바일 메뉴 · 스크롤 등장 · 카운트업 · 폼)
public/img/            여행지 사진 + CREDITS.json
scripts/sync-members.js  구글 시트 → CSV 동기화
```

## 8. 이미지 출처

여행지 사진은 위키미디어 커먼즈의 자유 이용 라이선스(CC0 / CC BY / CC BY-SA) 이미지입니다.
전체 목록과 저작자 표시는 `/credits` 페이지 또는 `public/img/CREDITS.json`에서 확인하세요.

## 9. 아직 하지 않은 것

배포는 하지 않았습니다. 로컬에서만 동작합니다.
실제 운영으로 옮길 때 필요한 것들:

- 세션이 메모리에 저장되어 서버 재시작 시 로그아웃됩니다
- 비밀번호가 생년월일 평문 비교입니다 (원본 사이트 정책과 동일하나 운영에는 부적합)
- 여권 사본 업로드, 결제 연동, 관리자 화면, 메일/알림톡 발송은 구현하지 않았습니다
- HTTPS, CSRF 토큰, 요청 제한(rate limit) 없음
